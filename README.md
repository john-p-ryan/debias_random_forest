# Debias Random Forest Regression Predictors

Python (`debiasforest`), Julia (`DebiasForest.jl`) and R (`debiasforest`) implementations of the
random forest bias-correction methods compared in Chen, Withana Gamage & Ryan (2022), with
reproducible simulations and a UCI Yacht regression demo.

## Methods

| Paper | Python | Julia | R |
|---|---|---|---|
| Un (uncorrected) | `default_forest()` or any fitted sklearn bagging ensemble | `fit_forest(X, y)` | `fit_forest(x, y)` or any `randomForest(..., keep.inbag = TRUE)` |
| De / Qu / Cu / Sp (univariate smoothing) | `SmoothedForestRegressor(method="linear"/"quadratic"/"cubic"/"spline")` | `fit(SmoothedForest, X, y; method=:linear/...)` | `smoothed_forest(x, y, method = "linear"/...)` |
| Bf, Bf(k) (boosted forest) | `BoostedForestRegressor(n_iterations=1, stopping="fixed"/"oob")` | `fit(BoostedForest, X, y; n_iterations=1, stopping=:fixed/:oob)` | `boosted_forest(x, y, n_iterations = 1, stopping = "fixed"/"oob")` |
| Cond (conditional bias, Lu & Hardin 2021) | `ConditionalBiasForestRegressor()` | `fit(ConditionalBiasForest, X, y)` | `conditional_bias_forest(x, y)` |
| Stopping rule (§2.2.2) | `select_n_iterations(X, y, max_iterations=6)` | `select_n_iterations(X, y; max_iterations=6)` | `select_n_iterations(x, y, max_iterations = 6)` |
| Full comparison | `predict_all_methods`, `simulation_study`, `repeated_splits` | same names | same names |

- All three packages track bootstrap (in-bag) membership, expose bias-corrected OOB predictions
  (`oob_prediction_` / `oob_prediction` / `predict(model)`), and can reuse one fitted base forest
  for every method.
- `n_iterations` is the number of residual forests fitted after the base forest:
  0 → Un, 1 → Bf (the paper's one-step correction, the default), k+1 → Bf(k); `paper_label(k)`
  gives the paper's notation.
- The spline method is R's `stats::smooth.spline` (GCV). The R package calls it directly; Python
  and Julia contain native ports (R's knot subset and spar search), checked against fixtures
  generated by `dev/spline_reference.R`.
- Forest defaults follow R `randomForest` as used in the paper: 500 trees,
  `mtry = max(floor(p/3), 1)`, node size 5. The R package uses `randomForest` itself; Python wraps
  scikit-learn (≥ 1.4); Julia builds DecisionTree.jl trees in its own bagging loop and provides an
  MLJ interface.

## Quick start

Python (3.10+):

```sh
uv venv --python 3.12 && source .venv/bin/activate
uv pip install -e "python[test,demo]"
```

```python
from debiasforest import BoostedForestRegressor

model = BoostedForestRegressor(n_iterations=1).fit(X_train, y_train)
y_pred = model.predict(X_test)
```

Julia (1.10+):

```julia
using Pkg; Pkg.develop(path="julia")
using DebiasForest
model = fit(BoostedForest, X_train, y_train; n_iterations=1)
y_pred = predict(model, X_test)
```

R (4.0+):

```sh
Rscript -e 'install.packages("randomForest")'
R CMD INSTALL r
```

```r
library(debiasforest)
model <- boosted_forest(x_train, y_train, n_iterations = 1)
y_pred <- predict(model, x_test)
```

See [`python/README.md`](python/README.md), [`julia/README.md`](julia/README.md) and
[`r/README.md`](r/README.md) for the full APIs.

## Layout

- `python/`: scikit-learn-compatible package and pytest suite (`cd python && pytest`).
- `julia/`: Julia package, MLJ models and tests (`julia --project=julia -e 'using Pkg; Pkg.test()'`).
- `r/`: R package and testthat suite (`Rscript -e 'testthat::test_local("r")'`).
- `demo/`: `debias_demo.ipynb` (Python), `debias_demo.jl` (Julia) and `debias_demo.R` (R), with
  committed tables in `demo/results/{python,julia,r}/` and figures in
  `demo/figures/{python,julia,r}/`.
- `dev/spline_reference.R`: regenerates the `smooth.spline` test fixtures (needs only base R).

## Running the demos

```sh
# Python (about 37 min on 4 cores; DEBIAS_DEMO_QUICK=1 for a ~30 s smoke run)
jupyter nbconvert --to notebook --execute --inplace demo/debias_demo.ipynb
# Julia (about 38 min with 4 threads; DEBIAS_DEMO_QUICK=1 for a smoke run)
julia -t 4 --project=demo demo/debias_demo.jl
# R (about 5.5 min with 8 cores; DEBIAS_DEMO_QUICK=1 for a ~40 s smoke run)
DEBIAS_DEMO_CORES=8 Rscript demo/debias_demo.R
```

The demos reproduce Fig. 1 (OOB prediction vs true function), Tables 1–2 (simulations with
K = 200 replications instead of 1000), Fig. 5 (test error vs boosting iterations) and the Yacht
row of Table 4 (100 random 2/3–1/3 splits). Yacht is downloaded on first use and cached in
`demo/data/` (UCI first, then a GitHub mirror); the Yacht sections are skipped when offline.

## Results compared with the paper

All three implementations reproduce the paper's rankings: boosted forests with one or two extra
iterations do best, and Functions 1–2 match Tables 1–2 closely. Functions 3–5 and Yacht have
different error magnitudes from the paper (lower for Function 3, higher for the rest). Per-language tables, with the paper's values alongside, are in
`demo/results/{python,julia,r}/`.
